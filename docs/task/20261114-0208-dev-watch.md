## Description

`pnpm dev` (nsl + Vite designer) serves every workspace package from its
build output, so each package change needs a manual `pnpm build` and a page
reload. Make package changes reach the designer without manual builds, while
keeping the number of watch processes small:

- plugins and the designer entry of the renderer are compiled from source by
  the designer's Vite in dev;
- the renderer UMD bundles (canvas, preview) are rebuilt by watchers, in a
  fast dev mode;
- materials, engine-ext and the material builder are watched only on
  request;
- the designer reloads the page when a served build output changes.
