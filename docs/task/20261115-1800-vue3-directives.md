# 20261115-1800-vue3-directives v-loading has no effect on Vue 3

- **status**: completed
- **priority**: P1
- **owner**: wudi
- **createdAt**: 2026-11-15 18:00

## Description

A node with `v-loading` shows no loading mask in the Vue 3 canvas and
preview ("Failed to resolve directive: loading"). Vue 2.7 works because
Element UI installs itself on `window.Vue` when its script loads; on Vue 3
nothing registers the directive: the canvas app is created by the adapter
and the materials export components only. It never worked on Vue 3.

## ActiveForm

Registering the directives of materials

- **blocked by**: (none)
- **blocks**: (none)

## Notes

A material exports `directives` (`{ loading: vLoading }`); `buildComponents`
registers them through `VueAdapter.registerDirective` (Vue 2:
`Vue.directive`; Vue 3: a registry of the adapter, read before
`resolveDirective`). The Element Plus material exports `vLoading`
(`scripts/materials/generate.cjs`).

Follow-up found in the designer: adding the directive to an already rendered
node crashed Vue 3's directive patch; the adapter keys the vnode by its
directive keys.

- complete: adapter API, library directives, Element Plus entry, unit and
