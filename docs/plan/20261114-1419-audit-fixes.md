## Context

Audit finding (repository audit of commit d422dd4): Small confirmed findings: the Vue 2 parent mixin recognises Leaf by name; Dependabot proposes Vue 3 for Vue 2 targets; plugins can be released before the tools they depend on; the editor's Vue 3 typings are a stale snapshot; materials build identical .min bundles twice.

## Proposal

- Leaf marker: `Leaf` carries the `__lowcodeLeaf` option (`LEAF_MARKER`,
  exported by the core); the Vue 2 parent mixin checks it instead of the
  component name, so an app component named `Leaf` keeps its parent.
- Dependabot (`.github/dependabot.yml`): npm (root and both scaffold
  templates) and GitHub Actions, weekly; majors of vue, vue-router, vant,
  ant-design-vue, element-ui and element-plus are ignored (per-target
  majors, upgraded by hand).
- Release order: `scripts/check-release-deps.mjs <group>` fails the release
  when a `workspace:` dependency on another group is not on npm yet.
- Editor typings: the Vue 3 / vue-router 4 typings are read from the
  installed packages at build time (`build/vue3-types.ts`,
  `virtual:vue3-types`), with the declaration chunks they import
  (vue-router 4.6's `router-<hash>.d.mts`). The designer self-hosts Monaco
  0.52.2 (`/runtime/monaco/vs`, from npm) and loads it into `window.monaco`
  before `init()`, so every copy of `@monaco-editor/loader` uses it instead
  of the CDN Monaco 0.31 (TypeScript 4.4, which cannot read Vue 3.5 types).
- Material builds: without source maps the plain files are minified, so the
  `.min` files are copies instead of a second identical build.

## Risks

- Preloading Monaco adds its download to the designer start.
- Monaco is pinned to 0.52.2: 0.53 changed the AMD build and 0.55 moved
  `languages.typescript`, which the editors use.

## Scope

Renderer core/vue2, `.github`, `scripts/`, vue-code-editor, designer,
material builder.

## Alternatives

- Passing `requireConfig` to every `MonacoEditor`: the setters in
  engine-ext and the official plugins bundle their own editors.

## Annotations

- Verified: unit tests (new: Leaf named host component, Vue 3 typings and
  chunks, single build without source maps), lint, lint:type; designer E2E:
  Vue 3 and Vue 2 editors report only the expected type error, setters and
  code generator dialogs work with the self-hosted Monaco.
