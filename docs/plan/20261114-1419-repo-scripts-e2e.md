## Context

Audit finding (repository audit of commit d422dd4): The meta generator, the screenshot capture and the designer E2E checks live in an ignored .tmp directory: metas cannot be regenerated from the repository and browser regressions are not caught by CI.

## Proposal

- `scripts/materials/`: `fetch-docs.cjs` downloads the docs of the
  library versions the materials install (tags read from their
  `package.json`) into `.cache/material-docs`; `scrape-antd1.cjs` reads the
  ant-design-vue 1.x site; `parse.cjs`, `generate.cjs <lib> [--write]`
  (formats its output with Biome), `recipes.cjs`, `capture.cjs`
  (`DESIGNER_URL`); `paths.cjs` maps the libraries to the materials.
- `e2e/` (Playwright 1.65.0, `playwright.config.ts`, `pnpm test:e2e`):
  designer loads in both Vue versions without errors; the code editor
  type-checks against the Vue typings; every material snippet renders;
  the code generator lists the project files and downloads a zip.
- CI job `e2e`: builds the designer, installs Chromium, runs the checks and
  uploads `test-results/` on failure.

## Risks

- The designer still loads the engine from the CDN until
  20261114-1419-designer-self-host; a slow CDN fails E2E (one retry in CI).

## Scope

`scripts/materials`, `e2e`, `playwright.config.ts`, CI, README, and the
generator fix below.

## Alternatives

- ESM rewrites of the scripts: no behaviour change, left as CommonJS.

## Annotations

- Regenerating all six libraries from freshly fetched docs reproduces the
  committed metas, except for a generator bug the E2E check found: the
  unprefixed names of Element Plus exports were weak and made no home page,
  so the `Table Attribute` table of config-provider created ElTable (wrong
  props, no ElTableColumn nesting rule). Fixed; ElTable now comes from the
  table page.
- The render check compares the canvas HTML, not its length: an empty
  ElAside is as long as the canvas placeholder.
- Verified: E2E 8/8 against the development and the production designer
  builds, material tests, lint, e2e type-check.
